Study Link Builder

A study link opens the online form with your choices. Fill in the required parts, then press "Make the link". This page keeps nothing you type. Opening a study link, here or on the online form, puts its setup in GitHub Pages' logs. See the online collection tutorial.

The link you opened filled in these addresses. Check each one.

    Instruments

    Choose one instrument, or add up to two more. The online form gives them one after another, in this order. A list holds one form of the PID-5 at most. How several instruments work.

    Where responses go A file lands in the participant's downloads folder. A web address, such as a Google Sheet's web app, or a Supabase table gets one row per participant. Set up a sheet or a table.
    Participants and recruiting site Not used

    The online form reads each participant's Prolific ID from the address. Paste the link, placeholders included, as the study URL. If Prolific's URL-parameters option adds them again, it reads the filled ones. The file gains prolific_study and prolific_session columns.

    The online form reads each participant's SONA survey code from the id parameter. Paste the link as SONA's Study URL. For completion, give SONA's client-side URL with {participant} for XXXX. Its credit token is readable in the study link.

    The online form reads each participant's Connect ID from the participantId parameter as their identifier. Give the link as the project URL in Connect, and Connect's completion redirect URL as the completion URL.
