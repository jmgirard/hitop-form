Make a study link

The link opens the form page with the instrument, the study and, when you give them, the participant, the module and the store to send responses to folded into its address. This builder keeps nothing and sends none of what you type anywhere. For a Supabase table it downloads the instrument from the hitop package's site, as the form page does. Give each participant a link. When they finish, the page sends their responses to the store you named, or, with none, saves them as a file in their own downloads folder.

  1. Choose the instrument and name the study. For part of the HiTOP-SR, build a module in the Module Builder first and paste its descriptor below.
  2. Say where the responses go: a file on the participant's device, a web address, or a Supabase table.
  3. Press "Make the link" and give the link to each participant. The online-collection tutorial walks the whole route, from the link to the scored responses.
