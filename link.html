Study Link Builder

A study link opens the online form. Fill in the required parts, then press "Make the link". The Study Link Builder keeps nothing you type. Opening a study link on either page puts its setup, or its setup file's address, in GitHub Pages' logs. See the online collection tutorial.

The link you opened filled in these addresses. Check each one.

    Instruments

    Choose one instrument, or add up to two more. The online form gives them one after another, and the responses hold their item columns, in this order. At most one PID-5 form. How several instruments work.

    Where responses go A file goes to the participant's downloads. A web address, such as an Apps Script web app, gets one JSON row per participant, and a Supabase table one row, a column per item. Set up a sheet or a table.
    Participants and recruiting site Not used

    The online form reads each participant's Prolific ID from the address. Paste the link, placeholders included, as the study URL. If Prolific's URL-parameters option adds them again, it reads the filled ones. The responses gain prolific_study and prolific_session columns.

    Paste the link, ending in id=%SURVEY_CODE%, as SONA's Study URL. There, each participant's survey code becomes their identifier. As the "Completion URL", give SONA's client-side URL with {participant} for XXXX. Its credit token is readable in the study link.

    The online form reads each participant's Connect ID from the participantId parameter as their identifier. Give the link as the project URL in Connect, and Connect's completion redirect URL as the completion URL.

    Your own questions Not used

    Questions of your own, asked on a screen before or after the form. Each answer goes in a column named q_ plus the question's name, after the item columns. As many as the setup's size allows. How answers are written.

    You can also write the questions in a spreadsheet. "Download a template" saves a CSV file with one example of each type. "Download these questions" saves the questions above.

    Where the setup is kept

    The study link can carry the whole setup, or name a JSON file you host, such as a file in a public GitHub repository. A file keeps the link short. How a setup file works.

    Download the setup file and put it on a public https:// host that lets other sites read it. Anyone can then read where responses go. After any change to the form, replace the hosted copy and make a new link.
