Make a study link

The link opens the form page with the instrument, the study and, when you give them, the participant, the module and the store to send responses to folded into its address. This builder keeps nothing and sends none of what you type anywhere. Opening a study link here to edit it (link.html?c=…, or link.html?z=… for a link with consent text or questions) puts its c or z parameter in this page's address, which your browser sends to the page's host when it requests the page. For a Supabase table the builder downloads the instrument from the hitop package's site, as the form page does. Give each participant a link. When they finish, the page sends their responses to the store you named, or, with none, saves them as a file in their own downloads folder.

  1. Choose the instrument and name the study. For part of the HiTOP-SR, build a module in the Module Builder first and paste its descriptor below.
  2. Say where the responses go: a file on the participant's device, a web address, or a Supabase table.
  3. Press "Make the link" and give the link to each participant. The online-collection tutorial walks the whole route, from the link to the scored responses.

The link you opened filled in these addresses. Check each one before you make a link.

    The page takes each participant's Prolific ID from the address as their identifier, so leave the participant field empty. Paste the link below, with its three placeholders, as the study URL on Prolific, which fills them in. Prolific's "I'll use URL parameters" option appends the three parameters to the study URL itself, so a pasted link carries each parameter once unless that option adds it again, and the page then reads the filled value. The file and the table gain two columns, prolific_study and prolific_session, after submitted (and after item_order under the random order).

    The page takes each participant's SONA survey code from the id parameter of the address as their identifier, so leave the participant field empty. The link below ends in id=%SURVEY_CODE%. Paste it as the Study URL in SONA, which puts each participant's survey code in place of %SURVEY_CODE%. For the completion URL, give SONA's client-side completion URL with {participant} in place of its XXXX. That URL carries the study's credit token, and a participant can read it in the study link.

    The page takes each participant's Connect ID from the participantId parameter of the address as their identifier, so leave the participant field empty. Give the link below as the project URL in Connect. For the completion URL, give the completion redirect URL Connect shows for the study.

    Your own questions

    Optional. Questions of your own, such as age or how the participant heard of the study. The page asks them on a screen before the form or on a screen after its last page, never beside the items. Each answer is written in a column named q_ plus the question's name, after the item columns. A text answer is written as typed. A whole number is written in digits. A choice is written as the number of the chosen option, counted from 1, and several choices as those numbers in order, separated by spaces. An unanswered question is written empty. Up to 50 questions. A link with questions is written compressed, as ?z=.
