# hitop-form

A static page that renders a HiTOP-SR or HiTOP-BR form from the
[hitop](https://jmgirard.github.io/hitop/) package's JSON export. It saves
each participant's responses to their own device. Nothing is sent anywhere.

Live page: <https://jmgirard.github.io/hitop-form/>. Make a study link at
<https://jmgirard.github.io/hitop-form/link.html>.

This README is completed as the page is finished.
